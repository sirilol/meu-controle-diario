MEU CONTROLE DIÁRIO — PWA corrigido

Arquivos:
- index.html
- manifest.webmanifest (com ícones, scope, start_url e display standalone)
- sw.js (cache offline e atualização do cache)
- icon-192.png
- icon-512.png

ATUALIZAÇÃO NO GITHUB PAGES:
1. Extraia este ZIP.
2. No repositório https://github.com/sirilol/meu-controle-diario, abra Add file > Upload files.
3. Envie e substitua os arquivos existentes: index.html, manifest.webmanifest e sw.js.
4. Envie também os dois arquivos novos icon-192.png e icon-512.png.
5. Faça Commit changes na branch main e aguarde o GitHub Pages publicar.

NO ANDROID:
1. No Chrome, abra o site.
2. Recarregue a página. Se continuar igual, abra em uma aba anônima para testar ou limpe os dados do site.
3. Abra o menu ⋮ e procure Instalar app.
4. Se a opção ainda não aparecer, feche e reabra o Chrome e aguarde alguns minutos após a publicação.

NOTA:
Não consegui inspecionar a resposta HTTP do seu GitHub Pages diretamente neste ambiente. A correção foi feita com base nos arquivos da primeira versão que gerei: o manifesto anterior não declarava os ícones 192x192 e 512x512, o que pode impedir a oferta de instalação pelo Chrome.
